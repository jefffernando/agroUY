## Procedimiento del seguimiento diario

1. Consultar Uruguay, búsqueda web y últimos 12 meses; contrastar con 90 días para contexto reciente. Para estacionalidad, ampliar a 5 años cuando exista una serie suficiente.
2. Comparar variantes de una misma intención: tractor/tractores; precio del novillo/ganado; pasturas/suplementación. No tratar términos y temas de Trends como equivalentes.
3. Revisar consultas principales y en aumento, descartando sentidos ajenos al agro. Registrar fecha, filtros, enlace y evidencia o CSV exportado.
4. Los valores 0–100 son interés relativo, no tráfico, personas ni volúmenes absolutos. Un cero puede reflejar datos insuficientes. No comparar puntuaciones de consultas independientes como si tuvieran la misma escala.
5. Contrastar con consultas y páginas de Search Console cuando sean accesibles. Priorizar ampliar artículos existentes y entregar como máximo tres propuestas justificadas. No publicar artículos automáticamente a partir de Trends.
6. Si hay bloqueo o datos insuficientes, dejar constancia; no inventar resultados ni eludir restricciones.
